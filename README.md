This template should help get you started developing with Tauri, React and Typescript in Vite.

- [VS Code](https://code.visualstudio.com/) + [Tauri](https://marketplace.visualstudio.com/items?itemName=tauri-apps.tauri-vscode) + [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)


## Prerequisites (Требования к окружению)
Общие зависимости (для всех ОС)

1. __Node.js (LTS версия)__ — Скачать с [nodejs.org](https://nodejs.org/en)
2. __pnpm__ — Менеджер пакетов. Устанавливается через терминал:

    ``` bash
    npm install -g pnpm
   ```
4. __Rust__ — язык для бэкенда Tauri. Устанавливается через [rustup.rs](https://rustup.rs/)

    __Важно:__ После установки Rust обязательно перезапустите терминал!

## СТАРТ

1. Клонируем репозиторий

   ``` bash
   git clone https://github.com/qvpvvq/music-player-tauri.git
   cd music-player-tauri
   ```
2. Установите зависимости
   ``` bash
   pnpm install
    ```
3. Запуск в режиме разработки
   ``` bash
   pnpm tauri dev
   ```
4. Сборка релизной версии
   ``` bash
   pnpm tauri build
   ```
   _Готовые установщики появятся в папке_ `src-tauri/target/release/bundle/`

## ЗАДУМКА ПРОЕКТА
__*СК - САУНДКЛАУД__

Короче это музыкальный плеер который через с ютуба/саундклауда должен подкачивать треки, в меню в хэдере или где-либо еще должен быть поиск, не знаю пока насчет механизма отображения "результатов поиска", имеется ввиду 2, а может и больше потенциальных вариантов
1. пользователь закидывает ссылку на видео в ютубе/песню в саундклауде, она скачивается на пк в папку песен, которая кстати также должна быть изменяемой(в плане юзер может выбрать другой путь до папки), ну и собственно она добавляется в его скачанные треки в самом приложении, потом он может закинуть ее в свой созданный плейлист и там дальше уже думать слушать ее или нет
2. через какую-то хуйню, сделать так что юзер вводит название трека, каким-то образом отображаются результаты поиска по этому названию (по идее можно просто распарсить то что выдал ютуб или ск), ну и он выбирает в этом списке песню и дальше происходит тоже самое что и в 1 варианте

Главной проблемой мне кажется то что ютуб и ск в некой стране заблокирован, и как мне кажется самой еблей будет разобраться именно с этим, пока хз.
MVP должен выглядеть просто как дефолтный плеер типо спотифая, но с хранением треков локально, не знаю кстати есть ли в спотифае отдельная панелька конкретно для очереди, но я вижу это так что она должн абыть отдельно от библиотеки треков
## POST MVP идеи
В будущем чтобы чем-то отличаться от "конкурентов" из вариантов придумал следующее
1. Эквалайзер
2. Микшер чтоб делать мэшап сходу (придется как-то подгонять скорость треков под один, а еще лучше сделать чтоб юзер мог выбрать скорость либо полностью свою, либо скорость одного из треков)

Replay Gain/ Loudness normalization - это короче когда треки меняются, в первом играл какой-то эмбиент, и чел поднял громкость там 70% +, а потом заиграл жесткий метал для мужиков, и чтоб чел не оглох либо плавно снижать громкость, либо предлагать юзеру фишкой из 2 пункта поставить громкость громкую
